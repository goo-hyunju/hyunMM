# hyunMM 기획서 (원본)

> 2026-08-24 사용자 제공 기획서를 정리한 것이다. 이후 구조 확정 과정에서 일부 결정이 이 문서와 달라졌다 — **확정 사항은 `docs/superpowers/specs/2026-08-24-ai-daw-structure-design.md`가 우선한다.** 주요 변경: (1) 제품 컨셉을 "AI 비트 생성기"에서 **AI DAW**(사람이 조작, AI가 협업)로 재정의, (2) 아키텍처는 옵션 A/B 중 **Electron 통합 앱 + 로컬 Python 서비스**로 확정, (3) MVP는 오픈소스 모델 로컬 추론.

## 요약 (Executive Summary)

PC를 서버로 활용한 AI 기반 비트 생성기. 목표 사용자는 음악 초보자부터 프로, 라이브 퍼포머까지. 비트박스·키보드 입력, 템포·믹서·이펙트 제어, 프롬프트 기반 스타일 지정 등 DAW와 AI 생성 기능을 융합한 통합 시스템.

- 오디오 엔진: JUCE/C++ 또는 Web Audio API로 크로스플랫폼 지원
- 실시간 스트리밍: WebSocket 기반 저지연 통신
- AI 모델: 텍스트·MIDI·오디오 입력 → 스템·샘플·MIDI 생성 (Jukebox: 아티스트·장르 조건부, MusicLM: 텍스트→고품질 음악). 스타일 전이·리믹스 변환 확장 가능
- 3단계 로드맵(MVP → 확장 → 제품 완성)
- 성능 지표: 지연(ms), 음질(주관 평가 + FAD), 안정성. ASIO/WASAPI 고려 시 10–20ms 이하 목표
- 보안·저작권·윤리: 데이터·출력 라이선스 관리, 콘텐츠 필터링
- 수익 모델: 유료/구독, 생성 루프 저작권 판매 등

## 1. 제품 개요

**목표 사용자**: 초보자(최소 설정으로 결과), 취미자, 프로(세밀한 조정), 라이브 퍼포머(저지연·직관 컨트롤).

**핵심 기능**

| 기능 | 우선순위 | 대안/비고 | 설명 |
|---|---|---|---|
| 비트박스 입력(녹음/타악기) | 높음 | 보컬 샘플링, MIDI 드럼 패드 | 마이크/드럼패드로 비트를 입력, AI가 패턴으로 변환 |
| 가상 키보드(MIDI) | 높음 | 실제 MIDI 키보드 연동 | 온스크린/외부 MIDI로 멜로디·화음 입력, 자동 반주 |
| 템포·리듬 설정 | 중 | 리듬 프리셋 | BPM·박자 설정 |
| 멀티트랙 타임라인 | 높음 | 자동 어레인지(제한적) | 트랙 관리, 타임라인 기반 편집 |
| 믹서(볼륨·팬·솔로·뮤트) | 높음 | 기본 볼륨 조절 | 트랙별 조절, 저지연 모니터링 |
| 오디오 이펙트 | 중 | 외부 플러그인 연동 | 리버브, 딜레이, EQ, 컴프레서 등 |
| 실시간 성능 제어 | 높음 | MIDI 컨트롤러 연동 | 라이브용 패드·노브, 저지연(10~20ms) |
| 자연어 스타일 프롬프트 | 높음 | 프리셋 스타일 | "어두운 일렉트로닉 비트" → 모델 파라미터 매핑 |
| 파형·스펙트럼 시각화 | 중 | 레벨 미터 | AnalyserNode 기반 실시간 시각 피드백 |

**사용 시나리오**

- 초보자: 프롬프트/패턴 선택 → AI 자동 생성 → 미리듣기·저장. 고급 기능은 숨김.
- 전문가: MIDI로 직접 연주 + AI 부분 보완 요청, 트랙별 이펙트 조정, 스템·MIDI로 DAW 임포트.
- 라이브: 연주 즉시 AI 반주 생성, 저지연 모니터링, 실시간 모디파이어.

## 2. 시스템 아키텍처

> **확정: Electron 통합 앱 + 로컬 Python 서비스** (아래는 원 기획의 비교 내용)

| 아키텍처 | 장점 | 단점 |
|---|---|---|
| 단일 통합 앱 | 네트워크 없이 초저지연, 단순 배포, 크로스플랫폼(JUCE) | 모델 메모리 부담, 전체 재배포 필요 |
| 프론트/백 분리 | 백엔드 스케일링·모델 교체 용이 | 네트워크 지연, 스트리밍 기술 필요, 서버 비용 |

- 네트워크·실시간: WebSocket 양방향 스트리밍, 오디오 버퍼 최적화. Windows ASIO/WASAPI, Mac CoreAudio. AudioWorklet/백그라운드 스레드로 오디오 우선순위.
- 저장: 파일시스템 기반(project.json + 오디오 파일). 규모 커지면 SQLite → MySQL/MongoDB 검토.
- 데이터 모델: USER → PROJECT → TRACK → CLIP → AUDIO_SAMPLE, TRACK에 EFFECT 적용.

## 3. AI 모델 설계

- **입력**: 자연어 프롬프트, MIDI, 오디오 루프(드럼 패턴 녹음 등)
- **출력**: ① 오디오 스템/샘플(10~30초 루프), ② MIDI 패턴(드럼·멜로디·베이스), ③ 변형/스타일 전이
- **모델 후보**: Transformer VQ-VAE+AR(Jukebox), Hierarchy Transformer(MusicLM), MIDI-GPT/MuseNet, Diffusion(Riffusion), GAN/Flow
- **학습·파인튜닝**: 대형 코퍼스 사전학습(MAESTRO ~200h, MusicCaps 등) 후 장르별 파인튜닝. MAESTRO는 CC BY-NC-SA 4.0 — 비영리 한정. 상업적 사용 시 퍼블릭 도메인/상용 라이선스 데이터 필요. 생성물 저작권은 약관에 명시.

## 4. UI/UX

- 모듈: 비트박스/키보드 패널, 트랙 타임라인, 믹서, 이펙트 랙
- 인터랙션: 클릭·드래그(클립 길이·이동), 실시간 MIDI 녹음, 단축키, 프롬프트 입력창(자동완성)
- 프롬프트 언어: 자연어 → 내부 파라미터(장르·악기·템포) 매핑, 키워드 토큰화 → 조건부 인코딩
- 시각화: 파형 뷰(AnalyserNode), 스펙트럼(FFT), 레벨 미터, 트랙 색상 구분

## 5. 개발 로드맵

3단계: **Phase 1 MVP**(기획·프로토타입·기본 생성 연동·기본 UI/오디오 엔진·단위 테스트) → **Phase 2 확장**(고급 기능·UX 개선·모델 튜닝·다국어·베타) → **Phase 3 제품화**(안정성·보안 강화·릴리스·유지보수). 기간: 2026-09 ~ 2027-08 (기획 시점 추정).

- MVP: 텍스트/비트 입력→오디오 생성 파이프라인, 기본 트랙/믹서 UI, 단순 이펙트, 파일 입출력, 30초 루프 생성 데모
- 인력(기획 시): AI 엔지니어 2, 오디오 엔지니어 1, C++/JUCE 1, FE 1, PM 1
- 하드웨어: 고성능 멀티코어 CPU, RTX 4090급 GPU, RAM ≥64GB, SSD ≥2TB, ASIO 오디오 인터페이스

## 6. 테스트·성능 지표 및 배포

- 지연: round-trip 10ms 이하 목표(ASIO 기준)
- 음질: MOS 주관 평가 + FAD(Frechet Audio Distance)
- 안정성: 장시간 구동 메모리 누수·크래시 테스트, 99% uptime
- 보안·저작권·윤리: SSL/TLS, "AI 생성물" 고지, 부적절 콘텐츠 필터
- 배포: 인스톨러(.exe/.dmg/.AppImage), 자동 업데이트, VST/AU/AAX 플러그인 확장 검토

## 7. 운영 및 수익모델

- 운영: 로그·에러 추적(Sentry 등), 생성 횟수·입력 타입·피드백 수집, 사용성 테스트
- 수익: 구독제/유료 라이선스(프리미엄 모델·샘플팩), 플러그인 판매, 스톡 음악 판매(생성물 상업적 사용권/공동 저작권)

## 8. 위험요인·대응 및 경쟁사

**위험·대응**: 모델 성능 부진(모델 융합·데이터 확보), 자원 부족(클라우드 GPU·경량화), 저작권·법적 문제(라이선스 준수·권리 고지), 사용자 수용성(기본/고급 모드 분리·튜토리얼), 경쟁 심화(MVP 집중·빠른 베타).

**경쟁사**

| 제품 | 주요 기능 | 가격 | 비고 |
|---|---|---|---|
| Suno AI | 텍스트→완성곡(보컬 포함) | 구독 | 다국어, 직관적 프롬프트 |
| Udio | AI 비트·루프 생성 | 무료/구독 | 웹 기반, 인스트루멘털 중심 |
| Boomy | 유저 앨범 제작·배포 | 무료+프리미엄 | 저작권 보장, 커뮤니티 |
| Mubert | 실시간 배경음악 스트리밍 | 구독(저작권 포함) | 크리에이터용 무한 루프 |
| Soundraw | 장르/무드/길이 선택→곡 생성 | 구독 | 상세 조정 제한적 |

**차별화**: DAW 통합 인터페이스 + 실시간 퍼포먼스 지원 → 이후 **AI DAW**(사람 주도 + AI 협업)로 컨셉 확정.
